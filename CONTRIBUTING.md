# Contributing

Thank you for your interest in this project.

This repository is **not open to external contributions**. While the source code is publicly available for transparency and reference, I am the sole maintainer and do not accept community contributions.

## What is not accepted

Please do **not** submit:

* Pull requests
* Feature requests
* Bug reports
* Issues
* Discussions
* Documentation contributions
* Any other form of collaboration related to the repository

Any pull requests or issues that are opened may be ignored or closed without review.

## Why?

This project is maintained exclusively according to my own roadmap, priorities, and development workflow. Keeping development centralized allows me to maintain consistency and make decisions without an external contribution process.

## The code

You are welcome to browse the source code and learn from it.

Thank you for respecting these guidelines.
